Project Web G-BBM = 

{

Nama Projek: Website Fullstack Gen-BBM

Tujuan: 

- Membuat profil komunitas berbasis website agar komunitas terlihat lebih profesional

- Menjadikan website ini sebagai jati diri untuk mengenalkan komunitas secara detail 

(Meliputi visi, misi, tentang kami, dan sejarah singkat berdirinya komunitas) 

- Membuat Sistem Informasi untuk komunitas dengan menyimpan aspek-aspek berikut:

1. Highlight Galeri dan Arsip Kegiatan

2. Dashboard Khusus Admin (CMS Khusus Admin (Non-IT bisa paham dan buat konten) -> Hanya mengedit isi konten saja seperti YouTube, untuk layout disesuaikan oleh programmer) untuk menyesuaikan highlight halaman utama terkait acara terbaru dan sistem CRUD untuk acara dan berita yang ditampil di page

3. Sebagai gerbang sumber daya dan pendaftaran terhadap Acara mendatang

4. Admin nanti bisa membuat acara baru, mengupdate konten acara yang sudah lewat atau belum lewat, tampilan seperti YouTube, dimana ada Proxy dan Detail acara

5. Website ini nanti bisa diupdate dari Hp melalui link khusus untuk email yang di-whitelist, sedangkan untuk tampilan terhadap user bisa diakses di browser

6. Setiap acara misal bisa memuat resource ringkasan kajian untuk acara seperti talkshow dan sejenis



Target User:

1. Pengguna Paling Penting - Admin & Pengurus Komunitas:

Kebutuhan: Dapat dengan mudah dan cepat memperbarui informasi acara, menambahkan berita/artikel, dan mengunggah foto/dokumen tanpa perlu keahlian coding.



Tujuan: Mengelola konten website secara efisien agar selalu relevan dan up-to-date.



2. Pengguna Utama: Anggota Aktif Gen-BBM

Kebutuhan: Mencari informasi jadwal kajian terbaru, melihat kembali dokumentasi acara yang terlewat, mengunduh materi kajian, dan merasa menjadi bagian dari komunitas yang aktif dan terorganisir.



Tujuan: Mendapatkan informasi yang cepat, akurat, dan terpusat.



3. Pengguna Sekunder: Calon Anggota & Publik Umum

Kebutuhan: Ingin tahu "Gen-BBM itu apa?", melihat kegiatan apa saja yang sudah dilakukan, memahami visi-misi, dan menemukan cara untuk bergabung volunteering.



Tujuan: Mendapatkan gambaran lengkap dan meyakinkan tentang komunitas sebelum memutuskan untuk bergabung pada suatu acara atau komunitas.



4. Pengguna Tersier: Pihak Sponsor

Kebutuhan: Dapat dengan mudah memahami rekam jejak komunitas secara terstruktur dan rapih.



Tujuan: Untuk meningkatkan probabilitas diterimanya sponsor pada acara-acara berikutnya.



Stakeholder utama:

1. Pengurus Gen-BBM

2. Calon Anggota & Publik

3. Pihak Sponsor



Fitur Utama (Minimum Viable Product - MVP)

Frontend (Tampilan untuk Pengguna)

- Halaman Utama (Homepage): Menampilkan highlight acara terbaru/mendatang, cuplikan berita/artikel terakhir, dan call-to-action untuk bergabung.

- Halaman Tentang Kami: Berisi Visi, Misi, Sejarah Singkat, dan mungkin struktur kepengurusan.

- Halaman Acara/Kegiatan: Daftar semua acara (mendatang & lampau) dalam format kartu (seperti galeri YouTube). Setiap kartu menampilkan thumbnail, judul, dan tanggal.

- Halaman Detail Acara: Halaman individual untuk setiap acara yang berisi deskripsi lengkap, waktu, lokasi, galeri foto/video, dan bagian "Sumber Daya" untuk mengunduh materi terkait (PDF, link, dll).

- Halaman Berita/Artikel: Mirip seperti halaman acara, tapi untuk konten tulisan.

- Halaman Galeri: Galeri foto dan video yang lebih komprehensif dari semua kegiatan.

- Halaman Kontak: Informasi kontak dan link media sosial Gen-BBM.



Backend (Dashboard Khusus Admin)

- Sistem Autentikasi Aman: Login khusus untuk admin yang emailnya sudah di-whitelist.

- Dashboard Utama: Tampilan ringkas untuk melihat statistik dasar dan shortcut ke menu - manajemen konten.

- Manajemen Acara (CRUD): Fitur untuk menambah, mengedit, dan menghapus data acara.

- Manajemen Berita/Artikel (CRUD): Fitur untuk menambah, mengedit, dan menghapus berita.

- Manajemen Media: Fitur untuk mengunggah gambar, video, dan dokumen (PDF) untuk galeri dan sumber daya acara.

- Editor Konten Sederhana (WYSIWYG): Editor teks yang user-friendly agar admin non-IT bisa membuat deskripsi konten dengan mudah (seperti menebalkan teks, membuat list, dll).



Nilai tambahan:

- SEO yang bagus 

- Clean Code, Skabilitas, dan Object Oriented 

- Aman dari serangan Hacker sehingga Cybersecurity-nya harus kuat



Fitur Lanjutan (Skalabilitas & Pengembangan Masa Depan)

- Sistem Pendaftaran Online untuk anggota baru.

- Sistem Registrasi Peserta untuk setiap acara.

- Forum Diskusi internal khusus anggota.

- Sistem Notifikasi Email/WA untuk pengingat acara.

}
